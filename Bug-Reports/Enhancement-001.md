## Enhancement: Indicate the Currently Selected Delivery Slot

**Module:** Buyer Portal – Change Delivery Slot / Request Redelivery

### Observation
When a buyer opens the Change Delivery Slot section after placing an order, the currently assigned delivery slot is displayed as an available selectable option.

For example, if the buyer has already selected 17:00–20:00 for a particular date, the same slot is still available for selection.

### Expected Behaviour
The currently assigned delivery slot should be clearly identified and should not be offered as an alternative selectable option for the same delivery date.
