**Title**: Generic Validation Message Displayed When Submitting Refund Request Without Selecting Any Product

**Severity:** Low  

### Description
When a buyer attempts to submit a refund request for a delivered order without selecting any product or quantity, the system displays a generic validation message: "Choose at least one line".

This message does not clearly explain which products or quantities need to be selected, particularly when the delivered order contains more than two product lines.

### Steps to Reproduce
1. Log in to the Buyer Portal.
2. Navigate to Order History.
3. Open an order containing more than two delivered product lines.
4. Click the Refund option.
5. Do not select any product or quantity.
6. Click the Submit Refund Request button.

### Actual Result
The system displays the generic validation message:

`Choose at least one line`

The message does not provide sufficiently clear guidance about the required product and quantity selection.

### Expected Result
The system should display a clear and user-friendly validation message explaining that the buyer must select at least one product and specify its quantity before submitting a refund request.
