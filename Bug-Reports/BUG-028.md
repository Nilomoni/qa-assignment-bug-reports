**Title:** Non-English Buyer Names Are Displayed as Question Marks in Logistics Export

**Module:** Operator Portal – Logistics CSV Export  
**Severity:** Medium  
**Priority:** P2  
**Related Requirement:** IF-02

### Description
Buyer names containing non-English characters are not properly preserved in the logistics CSV export. Instead, the exported file displays question marks.

### Steps to Reproduce
1. Create or use an order with a buyer name containing non-English characters.
2. Generate the Logistics CSV export.
3. Open the exported CSV file.
4. Check the buyer_name column.

### Actual Result
The buyer name is displayed as `????? ???????` instead of the original text.

### Expected Result
The original buyer name should be preserved and displayed correctly in the exported CSV using UTF-8 encoding.

Exported CSV Data: 
order_number	buyer_name	     delivery_address	                    delivery_date	  slot_start	slot_end	pieces

WC-01025-1	????? ???????	    8 Market Lane, Margao, Goa	           11/18/2026	      11:00	      8:00	      30
