**Summary:** 
[UI Issue] Previous Fixed Time value remains displayed after switching Store Clock to Real Time

**Severity** - Low


**Description**
When the Operator switches the Store Clock configuration from Fixed Time to Real Time, the previously configured Fixed Time date and time continue to appear in the input field.
This value remains visible even after saving the Real Time configuration and refreshing the page.

**Steps to Reproduce**
1. Log in to the Operator Portal.
2. Navigate to Store Clock settings.
3. Select **Fixed Time** and enter a date and time.
4. Save the settings.
5. Switch the Store Clock option to **Real Time**.
6. Save the settings.
7. Refresh the page.

**Expected Result**
After switching to Real Time and saving, the previously configured Fixed Time value should no longer be displayed, or should be clearly inactive.

**Actual Result**
The previously configured Fixed Time date and time remain displayed even after selecting Real Time, saving the settings, and refreshing the page.
