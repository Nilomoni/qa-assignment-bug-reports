**Bug:** Buyer Can Select Delivery Dates Beyond the Allowed 7-Day Window

**Severity:** Medium  

### Description
The delivery date picker allows buyers to select delivery dates beyond the permitted 7-day delivery window.

According to BR-05, buyers should only be able to select delivery dates from today up to the next 7 days. Dates beyond this period must remain unavailable.

### Steps to Reproduce
1. Log in to the Buyer Portal.
2. Add any product to the cart.
3. Navigate to the Checkout page.
4. Open the delivery date picker.
5. Navigate beyond the next 7 days.
6. Select a date beyond the permitted delivery window.

### Actual Result
The system allows the buyer to select delivery dates beyond the next 7 days.

### Expected Result
The buyer should only be able to select delivery dates from today up to the next 7 days. All dates beyond this window should be disabled or unavailable.
