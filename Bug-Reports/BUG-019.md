**Title**: Repeated Reorder Actions Increment Existing Cart Quantities Without Checkout

**Severity:** High  

### Description
When a buyer clicks the Reorder button for an existing order multiple times without completing checkout, the quantities of all products from the original order keep increasing in the cart.

Each subsequent click on Reorder adds the original order quantities to the existing cart quantities instead of handling the reorder consistently.


### Steps to Reproduce
1. Log in to the Buyer Portal.
2. Navigate to Order History.
3. Open an existing order containing multiple products.
4. Click the Reorder button.
5. Observe the products and quantities displayed in the cart.
6. Do not proceed with checkout or place the order.
7. Navigate back to Order History.
8. Open the same order again.
9. Click Reorder a second time.
10. Observe the product quantities in the cart.
11. Repeat the Reorder action and observe the quantity changes.

### Actual Result
Every time the buyer clicks Reorder, the quantities of all products from the original order increase in the cart.

For example, if the original order contains 2 units of each product:
- First Reorder: 2 units
- Second Reorder: 4 units
- Third Reorder: 6 units

The quantities continue accumulating even though the buyer has not completed checkout.

### Expected Result
Repeatedly clicking Reorder without completing checkout should not unintentionally duplicate the quantities of the original order.
