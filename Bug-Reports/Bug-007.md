**Summary:** Login Page Displays Raw API Validation Response When Username and Password Are Empty

**Severity:** Medium

### 1. Description
When a user clicks the Login button without entering a username and/or password, the application displays a raw API validation response in JSON format instead of showing a clear, user-friendly validation message.

### 2. Preconditions
- User is on the application Login page.
- Username and password fields are available.

### 3. Steps to Reproduce
1. Navigate to the Login page.
2. Leave Username and/Or Password fields empty.
3. Click the Login button.
4. Observe the error message displayed on the page.

### 4. Test Scenarios
- Both username and password are left empty.
- Username is entered, but password is left empty.
- Password is entered, but username is left empty.

### 5. Expected Result
The application should display clear, user-friendly validation messages near the relevant input fields.

Examples:
- "Username is required."
- "Password is required."

The application should not expose raw backend/API validation responses to the user.

### 6. Actual Result
The application displays the following raw JSON response:

`{"detail":[{"type":"missing","loc":["body","username"],"msg":"Field required","input":null},{"type":"missing","loc":["body","password"],"msg":"Field required","input":null}]}`
