**Title**: Seller-Cancelled Order Still Displays as Placed in Buyer Portal

**Severity:** High  

### Description
When a seller cancels an order before accepting it, the order status is not updated immediately in the Buyer Portal. The Seller Portal reflects the cancellation, but the Buyer Portal continues to display the order as `Placed`.

### Test Data
- Order Number: WC-01016-2
- Buyer: Spice Route Kitchen
- Order Amount: ₹2,352.00
- Initial Status: Placed

### Steps to Reproduce
1. Log in to the Buyer Portal.
2. Place an order.
3. Log in to the corresponding Seller Portal.
4. Locate the newly placed order.
5. Without accepting the order, click the Cancel button.
6. Log in to the Buyer Portal.
7. Navigate to Order History.
8. Check the status of the cancelled order.

### Actual Result
The Buyer Portal continues to display the order status as `Placed` even after the seller has cancelled it.

### Expected Result
As soon as the seller cancels the order, the Buyer Portal should immediately reflect the status as `Cancelled`.
