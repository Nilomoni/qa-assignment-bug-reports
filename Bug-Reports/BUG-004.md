**Summary:** Checkout Does Not Validate Products with Zero Available Stock

**Severity:** High

### Description
When a buyer adds a product with zero available stock to the cart, checkout does not display an insufficient stock validation error for that product, even though the product is unavailable at the seller's end.

### Preconditions
- Royal Poha stock is set to 0 in the Seller Portal.

### Steps to Reproduce
1. Log in as a seller.
2. Set Royal Poha stock to 0.
3. Log in as a buyer.
4. Add 2 pieces of Royal Poha to the cart.
5. Add other products with insufficient stock to the same cart.
6. Proceed to Checkout.
7. Observe the stock validation messages.

### Expected Result
Checkout should validate every cart item against the seller's available stock and display an insufficient stock error for any product.

### Actual Result
No error displayed when buyer add any data which is not available.
