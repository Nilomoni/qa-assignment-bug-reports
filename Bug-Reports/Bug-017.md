**Title**: Cancel Button Remains Active After Successful Order Cancellation

**Severity:** Medium  

### Description
After a buyer successfully cancels an order within the permitted 5-minute cancellation window, the Cancel button remains active on the Order Details page.
Although the backend correctly prevents the buyer from cancelling the same order again, the frontend does not update the button state. When the buyer clicks the active Cancel button again, the system displays the message "This order can no longer be cancelled".

### Steps to Reproduce
1. Log in to the Buyer Portal.
2. Place an order.
3. Navigate to the Order Details page.
4. Click the Cancel button within the allowed 5-minute cancellation window.
5. Verify that the order is successfully cancelled.
6. Observe that the Cancel button remains active.
7. Click the Cancel button again.

### Actual Result
- The order is successfully cancelled.
- The product stock is restored.
- The Cancel button remains active on the Order Details page.

### Expected Result
After successful order cancellation:
- The Cancel button should be disabled or hidden.


### Related Business Rule
**BR-11:** A buyer can cancel a sub-order within 5 minutes of placing it, including exactly 5 minutes, provided the order has not been shipped. Cancelled orders must remain in order history with Cancelled status, and the stock must be restored.
