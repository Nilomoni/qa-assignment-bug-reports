**Title**
**[Buyers – Cart] Quantity dropdown (1–20) is missing from the cart page**

**Severity:** Medium

**Description:**
As per the requirement, the cart page should provide a quantity dropdown containing values from 1 to 20 for each product. However, no quantity dropdown is displayed on the cart page.

**Steps to Reproduce:**
1. Log in to the application as a Buyer.
2. Navigate to the Products page.
3. Add any product to the cart.
4. Open the Cart page.
5. Observe the quantity field for the added product.

**Expected Result:**
A quantity dropdown containing values from 1 to 20 should be displayed for each product. Changing the dropdown value should update the product quantity in the cart.

**Actual Result:**
No quantity dropdown is available on the cart page.
