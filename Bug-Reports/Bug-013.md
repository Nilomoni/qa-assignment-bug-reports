**Title:** System Allows Repeated Refund and Exchange Requests for the Same Order Quantity after approve or waiitng for approval

**Severity:** High  


### Description
The system allows buyers to submit multiple refund or exchange requests for the same product quantity, even after the same quantity has already been requested or approved.
This allows the total refunded or exchanged quantity to potentially exceed the originally ordered quantity.

### Steps to Reproduce
1. Log in to the Buyer Portal.
2. Open a delivered order.
3. Submit a refund or exchange request for a specific quantity.
4. Log in as the Seller and approve the request.
5. Return to the same order as the Buyer.
6. Select the same product quantity again.
7. Submit another refund or exchange request.
8. Observe whether the system accepts the repeated request.

### Actual Result
The system allows repeated refund or exchange requests for the same quantity.

### Expected Result
The system must track previously approved refund and exchange quantities.

- The same quantity must not be refunded or exchanged more than once.
- Total refunded and exchanged quantities must not exceed the originally ordered quantity.
- Previously approved quantities must not be available for another request.
