**Title**
[Buyers – Order Placement] Success message does not display the order number after placing an order


**Description:**
As per the requirement, after successfully placing an order, the application should redirect the buyer to Order History and display the success message in the following format:

"Your order has been placed. Order number: {numbers}"

However, the application displays only "Order placed!" without including the order number.

**Steps to Reproduce:**
1. Log in as a Buyer.
2. Add products to the cart.
3. Proceed to checkout.
4. Click on the Place Order button.
5. Observe the success message displayed after placing the order.

**Expected Result:**
The application should redirect the buyer to Order History and display the success message with the generated order number with the message
"Your order has been placed. Order number: {numbers}"

**Actual Result:**
The application displays only "Order placed!" instead of the required success message containing the order number.
